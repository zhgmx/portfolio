---
title: Akasha
summary: A local-first personal memory CLI with full-text search, recall, and backups.
tech: Rust
order: 1
---

A local-first personal memory CLI that is still a work in progress. It captures encounters in SQLite, keeps original content in a content-addressed blob store, and provides full-text search, recall, context, processing jobs, archives, and backups.

It serves as a kind of second brain: everything you run into gets captured locally, addressed by its content, and made searchable. Recall and context pull it back when you need it, and the job system keeps processing, archiving, and backups running in the background.
