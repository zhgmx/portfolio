A Linux-native audio mixer for the Elgato Wave:3, providing Wave Link-style functionality using PipeWire.

Built in Rust on PipeWire with a Qt6/Kirigami interface. It gives you independent control over five channels (system, voice, music, browser, game), separate stream and monitor mixes, automatic app routing, profiles, and mic control for the Wave:3.

This project was mainly intended to experiment with Claude's Rust capabilities, back when Opus 4.5 was still a relevant model.
